Sprint 0

Wat heb ik gedaan?

Dit waren de eerste 2 weken van de minor. Tijdens dit project hebben we een eigen website gemaakt waarin je je 3 leerdoelen moest verwerken. Verder moest je 2 thema's hebben, data ophalen uit een API en met die data je klasgenoten in je website verwerken. Je mocht helemaal zelf bepalen waar de website over ging.

Aangezien ik zelf een passie heb voor games, de minor Applied Game Design heb gedaan leek het me leuk om een platformer te maken in een canvas. Je bestuurt een poppetje en kan links/rechts lopen en springen. Je kunt 3 boeken vinden en daarin mijn leerdoelen vinden. Verder heb ik een knop waarmee je het thema kan veranderen naar een water thema, waardoor je verder naar boven kunt zwemmen. Ook had ik een invoerveld waar je je naam in kunt zetten en aan de hand van je naam, kreeg je de favoriete kleur die je hebt gekozen in de API.

Wat heb ik geleerd?

Aangezien dit het begin was van de minor, was dit vooral het moment om gewend te raken aan hoe we tijdens de minor zullen werken. Elke dag werken aan een opdracht en in je README bij houden wat je hebt gedaan en hoe dat ging. Verder hebben we elke dag een checkout waarin je het werk van een ander kan zien, reflecteert op je eigen werk en bepaalt wat je morgen gaat doen. Ik vind dit wel een fijn systeem om te hebben tijdens de minor.

Ik had al ervaring met een platformer maken in canvas. Het was vooral fijn om weer te kunnen wennen aan code aangezien het weer een tijdje geleden was. Ook hadden we geleerd hoe je met Github werken en hoe je data fetcht uit een API. Deze dingen waren niet per se nieuw maar het was fijn om na anderhalf jaar weer de basics te kunnen.

Wat vond ik ervan?

Ik vond het leuk om het vak een beetje vrij te beginnen. Je kon in principe doen wat je zelf wilde. Ik denk dat de website die ik heb gemaakt wel bij mij past. Het was een goede manier voor iedereen om te laten wat ze kunnen en wat ze willen leren. Ik vind het lastig om leerdoelen voor mezelf te stellen aangezien het vaak dingen zijn die je zowieso wil gaan doen, zoals betere code schrijven. Uiteindelijk heb ik wel 3 leerdoelen geschreven waarmee ik verder kon.
