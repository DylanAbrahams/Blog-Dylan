CSS To The Rescue

Wat heb ik gedaan?

Tijdens dit vak hebben we een interactieve website gebouwd met CSS, zonder gebruik te mogen maken van JavaScript. Voor mij wel een uitdaging aangezien ik altijd JavaScript gebruik. Je mocht kiezen tussen 4 thema's: Control Panel, Silly Walk, Abstract en Rubiks Kubus. Ik wilde mezelf uitdagen en heb ervoor gekozen om een Rubiks Kubus te maken zonder JavaScript.

Uiteindelijk heb ik een 2x2x2 kubus gemaakt die je kunt besturen met knoppen. Ik heb kunnen fixen dat je verschillende richtingen kunt draaien voor zowel de voorkant als de bovenkant. Verder kun je die 2 draaien combineren. Omdat elke draai eigen CSS styling heeft zijn het uiteindelijk 25 verschillende knoppen voor maar 2 kanten draaien. Daarvan heeft elke knop eigen styling voor elk individueel blok.

Wat heb ik geleerd?

Tijdens dit vak heb ik veel verschillende CSS features geleerd die ik nog niet kende, waaronde :has(), nesting, perspectives, corner shapes, clip-paths etc. Dit was de eerste keer dat iets 3D heb gemaakt met CSS. Verder heb ik me verbeterd in animaties maken met CSS.

Dit vak was wel pittig. Ik moest meerdere dingen proberen voordat de kubus uiteindelijk kon draaien op de manier hoe ik dat nu heb. Verder was ik er niet aan toe gekomen om het met een 3x3x3 kubus te doen. Na de beoordeling was het wel duidelijk dat ik wel wat vaker om hulp/advies mag vragen ipv zelf op een overbodige manier een oplossing te verzinnen.

Wat vond ik ervan?

Dit was een leuk vak. Het was leuk om iets te maken met volledige vrijheid en te kunnen focussen op CSS. Het was ook leerzaam aangezien ik van de 3 talen het minste ervaring heb met CSS. Achteraf had ik wel voor een van de andere themas gekozen. Het was een leuke uitdaging om een kubus te maken met CSS maar ik had mezelf een beetje gelimiteerd met het maken van creatieve ontwerpen met CSS. Zowel qua thema als qua tijd die ik allemaal had besteed aan de kubus zelf. De styling is best simpel, maar ik had wel een dark theme gemaakt die wat interessanter is geworden. Ik vond het een succes, maar als ik het vak zou overdoen, zou ik iets heel anders hebben gemaakt.

Cijfer

7.5
