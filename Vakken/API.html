API

Wat heb ik gedaan?

Voor dit vak moesten we een website maken waar we content ophalen uit een API. We hadden vrije keuze waar het over ging.Verder moesten we gebruik maken van 2 Web API's. Ik heb een Pokemon website gemaakt met behulp van PokeAPI, verder heb ik qua web API's Canvas & LocalStorage. Ik heb een overzichtspagina met alle Pokemon van generatie 1 met elk een detailpagina met meer informatie over elke pokemon in de stijl van Pokemon Trading kaarten.

Mijn beste onderdeel van mijn site daarentegen was de wereld pagina. Op een canvas kun je een speler besturen op een kaart en rondlopen in het gras tot je een willekeurige pokemon hebt gevonden, net als in het echte Pokemon spel. Als je een pokemon hebt gevonden, kun je deze vangen. Deze wordt vervolgens opgeslagen in de localstorage.

Wat heb ik geleerd?

Ik had een best ambitieus idee voor dit project. Ik had gelijk advies gekregen om het randomizen en vangen van pokemon eerst button only te maken. Dit bleek voor mij heel handig. Elke week had ik iets nieuws op mijn website. Week 1: Overzichtspagina, Week 2: Detailpagina + Randomizer, Week 3: Canvas Wereld, Week 4: Canvas Encounter, Week 5: Polish. Qua styling heb ik tijdens het vak ook veel feedback gekregen. Aangezien ik veel focus had gelegd op de functionality, was ik wat minder bezig met styling. Maar alsnog heb ik, vooral in week 4, tijd kunnen nemen om goede styling toe te passen na er feedback over te krijgen.

Er waren meerdere functies die ik nog graag erin had willen zetten, waaronder starter pokemon en een battle systeem, maar ik heb ervoor gekozen om te focussen op wat ik had en dat dat er goed uitkwam, waaronder een pokeball animatie, audio en styling. Het is beter om wat functies te scrappen zodat je de rest beter uit kan werken. Verder had ik nog wat feedback over het iets beter organiseren van mijn code en mijn code duidelijk vermelden in mijn README.

Wat vond ik ervan?

Dit is denk ik mijn favoriete vak van de minor. Ik heb hier het meeste plezier in gehad en het meeste moeite in gestopt. Ook in de meivakantie heb ik elke dag een stukje eraan gewerkt. Het was tof om in principe zelf een heel pokemon spel te kunnen maken. Verder had ik veel aan de feedback van Cyd, wie mij veel advies gaf over waar ik het beste mijn tijd in kan stoppen en wat ik beter kan laten liggen.

Cijfer

9.5
