Browser Technology

Wat heb ik gedaan?

Voor het bak BT (Browser Technology) hebben we de opdracht gekregen om een formulier te maken van de erfbelasting in de huisstijl van de NS. Het voorbeeld dat we kregen was op papier met verschillende design keuzes die niet nodig zijn als je het formulier digitaal invult, zoals teksten die je door verwijzen naar een andere pagina en velden die je voor meerdere personen moet invullen. Daarbij moest je minimaal 2 patterns gebruiken die werken in het formulier.

Ik heb gekozen om onderdeel 1 en onderdeel 4 van de erfbelasting na te maken. Ik heb ervoor gezorgd dat het formulier is opgedeeld in verschillende pagina's. Dit heb ik gedaan door elk onderdeel een aparte class 'tab' te geven, alle niet actieve tabs de class 'inactive' te geven en de actieve tab 'active'. Hiermee kon ik ervoor zorgen dat maar 1 tab tegelijk zichtbaar is. Verder kun je met knoppen tussen de pagina's navigeren. Daarnaast heb ik rekening gehouden met validatie, als je iets niet goed invult, krijg je daar feedback op en progressive enhancement, ondanks ik veel JavaScript heb gebruikt, kun je het formulier zonder JS nog steeds gebruiken. Verder had ik nog toegevoegd dat je meerdere formulieren (voor onderdeel 4) kunt aanmaken voor elk persoon.

Wat heb ik geleerd?

Ik wist van tevoren niet hoeveel detail er nodig was om een goed en werkend formulier te maken met HTML en CSS. HTML elementen zoals fieldsets en legends waren voor mij nieuw. Verder allemaal trucjes met inputs en labels waarmee je het formulier zo toegankelijk mogelijk maakt, waren voor mij ook heel leerzaam.

Ik heb wel ervaring met code en eerder formulieren gemaakt dus ik wilde mezelf wel uitdagen met dit project. Ik denk dat dat wel is gelukt. Wel heb ik nog wat verbeterpunten. Ik had vaak JavaScript gebruikt, terwijl ik dingen ook met alleen HTML/CSS had kunnen doen, wat aan de enige kant wel leuk is dat ik het zelf can maken, maar ook onnodig omdat het al bestaat en al uitgewerkt is. Ik moet voortaan eerst kijken naar alternatieven in plaats van gelijk zelf te beginnen.

Wat vond ik ervan?

Ik vond dit een heel leerzaam vak. Verder kon ik lekker veel focussen op het schrijven van code. Ik vond de inhoud alleen wat minder. De NS stijl is niet bepaald interessant en ook niet echt mooi. Heel veel sites van studenten leken op elkaar. Daarnaast hoewel ik veel geleerd heb over formulieren had ik niet per se 4 weken nodig om formulieren te begrijpen. Prima vak, maar niet de beste.
