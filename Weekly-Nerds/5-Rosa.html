Wat is een hacker?

Een hacker is iemand die skilled is in technologie en op niet-standaard manieren zijn of haar doelen bereikt.

Doe het zelf, maar niet alleen

  • Samen met mensen die weinig van tech weten kleine techprojecten doen (Arduino-achtig)
  • Bijvoorbeeld PS controllers uit elkaar halen om nieuwe dingen te maken
  • Hoe meer je zelf maakt, hoe meer controle je hebt

Planned Obsolescence

  • Werkt reparatie en hacken actief tegen
  • Leidt tot de gedachte dat je altijd iets nieuws moet kopen
  • Vergroot afhankelijkheid van fabrikanten

De plek van een website

  • Een website leeft op een server (een computer met een router)
  • Die server staat vaak in een “random rechthoekig gebouw” (datacenter)

Kan het ook anders? Ja — websites kunnen anders worden opgebouwd voor andere resultaten, soms met minder goede prestaties of afbeeldingen.

Servers

Een server is simpelweg een computer + een router.

Gebruik maken van de middelen die je al hebt is belangrijk.

Static Site Generators

  • Minder impact op de server
  • Werkt met markdown bestanden
  • Leesbare en simpele code
  • Wordt vaak maar 1x per dag geüpdatet

Progressive enhancement

  • CSS animaties blijven werken als JavaScript uit staat

Takeaway

Objecten uit elkaar halen om ze te repareren in plaats van nieuwe te kopen.
