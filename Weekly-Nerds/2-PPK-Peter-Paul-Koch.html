Internet

Internet is het transport van de browser.

Geschiedenis van browsers

  • HTML - Skelet van je site
  • CSS - Opmaak van je site
  • DOM - Kopie van HTML geschikt voor JavaScript
  • AOM - Accessibility Object Model - Speciaal voor screenreaders
  • Interface - Waar je URL’s invoert en navigeert
  • JavaScript Engine - Verwerkt JavaScript code

Je schrijft JavaScript, de engine voert het uit.

De browser haalt informatie op en stuurt dit terug via de DOM.

HTML/CSS Parsers

Parsers lezen code en zetten dit om naar logica binnen de browser.

  • Bijvoorbeeld: p wordt een paragraaf.

Layout

Hoe HTML en CSS uiteindelijk weergegeven worden.

  • Probeer layout zo min mogelijk aan te passen.
  • Layout wijzigingen zijn zwaar voor performance.
  • Doe het liever direct goed.
  • Houd het simpel.

Rendering Engine

  • Niet hetzelfde als de interface of JS engine.
  • Verantwoordelijk voor HTML/CSS parsing en rendering.
  • Bouwt de DOM en AOM trees op.

Chromium werkt op meerdere browsers zoals Chrome, Edge en Opera.

Sommige browsers ondersteunen andere features dan anderen.

Core vs DOM

  • Core - Wat JavaScript een programmeertaal maakt.
  • DOM - Hoe JavaScript HTML kan aanpassen.

Render Blocking

De browser moet bepalen welke bestanden eerst geladen worden.

  • CSS blokkeert rendering.
  • JavaScript blokkeert ook, tenzij async of defer gebruikt wordt.
  • script src = NU
  • script defer src = LATER
  • script async src = MAAKT NIET UIT MAAR NIET NU

De browser wacht met HTML verwerken totdat duidelijk is wat JavaScript doet.

  • Laad grote JS bestanden later met async.
  • Of plaats JavaScript onderaan je HTML.

CSS wordt eerder geladen zodat je geen ongestijlde HTML ziet.

Backward Compatibility

Als iets ooit gewerkt heeft in een browser, moet het blijven werken.

  • DOCTYPE ondersteunt nog oude Internet Explorer functionaliteit.
  • form.object elements werkt nog steeds.
  • body bgcolor werkt nog steeds.
  • frameset werkte met opgesplitste HTML pagina’s.

Blinkende tekst werd uiteindelijk verwijderd.

Sommige historische browserfouten bestaan vandaag nog steeds.

Browsers

WWW Browser (1990)

  • Eerste browser door Tim Berners-Lee.
  • Herbouwd in 2019.
  • https://worldwideweb.cern.ch

Mosaic (1993)

  • Introduceerde afbeeldingen.
  • Was non-profit.

Netscape (1994)

  • Gemaakt door dezelfde mensen als Mosaic.
  • Betaalde browser.
  • Later Mozilla.

Internet Explorer (1995)

  • Microsoft maakte de browser gratis.
  • Dat veranderde de browsermarkt volledig.

Opera (1995)

  • Was vroeger populair.
  • Volgens Peter Paul Koch nu minder relevant.

IE 5 Mac (2000)

  • Apple werd ondersteund door Microsoft.
  • Werkte anders dan IE op Windows.

Konqueror (2000)

  • Begon als Linux hobbyproject.
  • Loste veel problemen van eerdere browsers op.

Safari (2003)

  • Gebruikt Webkit rendering engine.
  • Webkit bestaat nog steeds.

Firefox (2004)

  • Opvolger van Netscape.
  • Gemaakt door Mozilla.

Safari iOS (2007)

  • Eerste populaire mobiele browser.
  • Introduceerde touch events.
  • Andere mobiele browsers gebruikten ook Webkit.

Chrome (2008)

  • Google vond dat Apple te weinig deed.
  • Gebaseerd op Webkit.

Flow (2020)

  • Niet gebaseerd op bestaande rendering engines.
  • Ondersteunt sommige CSS onderdelen niet.
  • Gemaakt door een Engels persoon.

Ladybird (2024)

  • Vergelijkbaar idee als Flow.
  • Gemaakt door een Zweedse ontwikkelaar.

Browsermarkt 2024

Chrome domineert, gevolgd door Safari en Firefox.

Igalia

  • Spaans open source bedrijf.
  • Werken aan onderdelen van rendering engines.
  • Bijvoorbeeld grids in Chrome.
  • Maken geen eigen browser.
